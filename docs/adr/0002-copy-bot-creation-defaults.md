# Copy bot configuration at creation

Accepted on 2026-10-27. Each bot receives its own copy of the initial configuration,
including provider/model/reasoning values and starter soul. Changing creation
defaults affects future bots only; the owner edits an existing bot explicitly.
This replaces live inheritance so a default change cannot silently reconfigure
existing bots. Already accepted work retains its captured configuration, while
permission restrictions and revocations remain live under the accepted approval
policy. The owner confirmed the complete initial bot agreement in the
[accepted resolution](https://github.com/lancewilhelm/Staf/issues/14#issuecomment-6455172896). See the
[initial bot review](../mvp.md#initial-bot-contract-review--2026-10-27).
