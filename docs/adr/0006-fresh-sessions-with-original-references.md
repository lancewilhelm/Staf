# Start fresh sessions and reference original conversations

The owner explicitly rejected compaction on 2026-11-03. An agent can start a
fresh conversation session while retaining its identity, soul, memory, and
older conversations. Older sessions remain original sources that the owner
or an authorized agent can search, read, and reference explicitly. Staf must
not silently summarize, truncate, or replay them into a new session.

This resolves the direction left open in
[long-lived context planning](https://github.com/lancewilhelm/Staf/issues/11).
It favors explicit source access over a synthesized replacement for history.
Session identity belongs to accepted work, so a later session change cannot
retarget a command, its results, its references, or an uncertain retry.
